## Why

Для локальной диагностики полного HTTP-обмена сейчас недостаточно безопасного audit-журнала: он намеренно не сохраняет тела запросов и ответов. Нужен явно включаемый debug-режим, который записывает фактические входящие и исходящие данные публичного API в отдельный файл.

## What Changes

- Добавляется `PII_LOG_LEVEL` со значениями `info` и `debug`; значение по умолчанию — `info`, неизвестное значение блокирует запуск.
- При `PII_LOG_LEVEL=debug` сервис записывает JSONL-события с сырыми телами запросов и ответов публичного API в фиксированный файл `/var/log/pii-service/debug.jsonl`.
- Debug-журнал охватывает `/process`, `/v1/pii/*` и `/v1/runtime/chat`, включая ошибочные ответы; health, metrics и внутренние вызовы model worker/LLM не включаются.
- HTTP-заголовки, включая `Authorization`, не записываются. Для маршрута удаления scope сохраняется шаблон маршрута, а не фактический `scope_id` из URL.
- В `info` debug-файл не создаётся и тела не записываются; существующий audit-журнал продолжает работать без изменения формата.
- При `debug` невозможность безопасно открыть фиксированный файл является ошибкой запуска. Файл открывается только на добавление с правами `0600`.
- **BREAKING**: debug-режим сознательно разрешает хранение исходного и восстановленного текста, PII и токенов в локальном файле и заменяет прежнее требование о безусловном запрете request/response body в логах.

## Capabilities

### New Capabilities

- `debug-http-logging`: управляемое через environment логирование сырых тел публичного HTTP API в локальный JSONL-файл.

### Modified Capabilities

Нет: основные спецификации ещё не архивированы. При последующей синхронизации `pii-api` новое требование должно заменить конфликтующие сценарии активного change `add-reversible-russian-pii-protection`.

## Impact

- Конфигурация: `internal/config`, `PII_LOG_LEVEL`, Docker Compose и эксплуатационная документация.
- HTTP wiring: внешний middleware публичного API, который ограниченно буферизует request/response body и не меняет ответ клиенту.
- Файловая система: каталог `/var/log/pii-service` должен существовать и быть доступен на запись; для контейнера потребуется volume или bind mount, если журнал должен переживать пересоздание.
- Безопасность: debug-файл содержит чувствительные данные и требует прав `0600`, ограниченного срока хранения и явного эксплуатационного предупреждения.
- Тесты: конфигурация уровней, отсутствие файла в `info`, полные тела и error path в `debug`, исключение заголовков, health/metrics и внутренних вызовов, сохранение HTTP-интерфейсов (`Flusher`, `Hijacker`, `Pusher`, `ReaderFrom`).
